# Amipatitas Paws And Purpose

Rol: Eres un diseñador UX/UI y desarrollador web senior fronted con experiencia en desarrollo en páginas creativas.

TAREA: crea una aplicacion para adoptar perritos que se llame "Amipatitas", quiero que la páginasea sobre un refuigio para perritos, que la página te de la imagen de cada perrito y abajo una descripcion de su nombre, sexo, tamaño aproximado, raza, aproximado de edad, listado de vacunas, temperamento y si es amigable con otros perritos.
Quiero que el usuario desplaze cada foto a la derecha si lo quiere adoptar y hacia la izquierda si quiere seguir buscando otro perrito. Además si desliza a la derecha muestre mas fotos del perrito, y que te despliegue un menú donde puedas agendar una cita y te de la opción de ser por video llamada o prescencial, que el menú te pida los datos de contacto como nombre, correo, número de telefono, domicilio, fecha y horara de cita.
Además quiero que tenga la opción para comprar artículos de cuidado de perritos como todo tipo de articulos de higiene para perro,  juguetes, camas para perro de diferentes tamaños, carnazas, premios.
Que tambien tenga un apartado para donar donde el menú contenga nombre, monto a donar, datos de tarjeta.
Y cualquier otro dato que te resulte relevante para la página y sus mejoras.
